Controlling a heat pump by electricity price

Heat pump

EnergyWizard doesn't talk to the heat pump by guessing at its menus. Every supported heat pump has its own driver - a small, clearly scoped code module that knows exactly how that brand accepts commands (SG Ready contacts, Modbus, or a local web API, depending on the brand).

Today there's a finished driver for Thermia/Husdata, and the architecture is built so new brands (NIBE, IVT, CTC, Mitsubishi) can be added as their own modules without touching the rest of the control logic - the same pattern already used for cars (Nissan/Tesla/generic EV) and inverters (SolarEdge).

The actual decisions - when should the pump run hard, when should it rest - are made by a shared priority engine, not by the driver. That means the whole control logic (electricity price, solar surplus, demand tariffs, the thermal battery) is identical regardless of which brand is actually sitting in the basement.

Missing a driver for your brand? That's exactly the kind of contribution this project is built to take - see the code on GitHub.
