# EnergyWizard

Minut-för-minut styrning av elbil, värmepump, solcellsexport, spabad och
huvudsäkring efter spotpriset - som ett vanligt Home Assistant-tillägg,
ingen docker-compose krävs. Se [DOCS.md](DOCS.md) för installation och
begränsningar (bara huvudmotorn paketeras i den här första versionen - inte
mobilappen/webdashboarden än).

Fullständig dokumentation: [huvudrepot](https://github.com/murre87/energywizard).
